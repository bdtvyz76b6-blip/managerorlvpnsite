1. Общие положения

Настоящее Пользовательское соглашение регулирует порядок использования сервиса «Орёл VPN».

Используя сервис, пользователь подтверждает согласие с условиями настоящего соглашения.

2. Назначение сервиса

«Орёл VPN» предоставляет пользователям сервис защищённого интернет-соединения.

Сервис предназначен для повышения конфиденциальности при передаче данных и обеспечения безопасного подключения к сети Интернет.

3. Регистрация

Для использования сервиса пользователь взаимодействует с Telegram-ботом Орёл VPN.

При регистрации сохраняются только данные, необходимые для предоставления сервиса.

  • Доступ предоставляется после оформления подписки.
  • Срок действия подписки зависит от выбранного тарифа.
  • После окончания срока подписка автоматически прекращает действие.
  • Для продолжения использования требуется продление подписки.

5. Обязанности пользователя

  • Использовать сервис в соответствии с законодательством своей страны.
  • Не передавать персональную ссылку третьим лицам.
  • Не предпринимать действий, нарушающих работу сервиса.

Администрация сервиса принимает меры для обеспечения стабильной работы сервиса, однако не гарантирует отсутствие технических сбоев.

7. Изменение условий

Администрация вправе изменять настоящее соглашение без предварительного уведомления пользователей.

Актуальная версия соглашения всегда публикуется на данной странице.
