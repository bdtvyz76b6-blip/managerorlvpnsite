Политика конфиденциальности

1. Общие положения

Настоящая Политика конфиденциальности определяет порядок обработки информации пользователей сервиса «Орёл VPN».

2. Какие данные собираются

  • Telegram ID пользователя.
  • Имя пользователя Telegram (если доступно).
  • Информация о сроке действия подписки.
  • Статус оплаты.
  • Персональная ссылка на подписку.

3. Для чего используются данные

  • Предоставление доступа к сервису.
  • Выдача и продление подписок.
  • Работа службы поддержки.
  • Информирование пользователя о статусе подписки.

4. Передача данных третьим лицам

Администрация не продаёт и не передаёт персональные данные пользователей третьим лицам, за исключением случаев, предусмотренных законодательством.

5. Хранение информации

Информация хранится только в объёме, необходимом для функционирования сервиса и предоставления оплаченных услуг.

6. Защита данных

Администрация принимает разумные организационные и технические меры для защиты информации пользователей от несанкционированного доступа.

7. Права пользователя

  • Получить информацию о своих данных.
  • Запросить удаление данных после прекращения использования сервиса, если их хранение не требуется по закону.
  • Обратиться в службу поддержки по вопросам обработки данных.
